## 1. 项目定位

### 1.1 这是什么

一个 **VOCALOID Music Creator / 二创剪辑作者** 的个人官方网站。

三条身份主线，在网站上并列呈现：

| 身份 | 表述 | 说明 |
|---|---|---|
| 主身份 | **Vocaloid Music Creator** | 站点核心，权重最高 |
| 副身份 | **二创剪辑作者** | 过往积累，有大爆作，是引流主力 |
| 虚拟角色 | **メキチャン（mekichann）** | 破軍星の終焉煌めき，视觉与叙事载体 |

> **命名约定（重要）**
> 角色自设名为 **メキチャン（mekichann）**。
> **キメラ（kimera）** 是角色的**性别**设定，源自重音テト的性别，亦代表本人中性。
> 两者不可混用：名称用「メキチャン」，性别用「キメラ」。
> 英文/罗马音一律写 **mekichann**，不写 chimera。

### 1.2 目标

- **短期**：把已有的二创爆作沉淀成一个能长期挂着的作品档案，替代散落的平台主页
- **长期**：以 Vocaloid Music Creator 的身份接到稳定的合作与委托

### 1.3 目标观众

| 优先级 | 人群 | 他们想找什么 |
|---|---|---|
| 1 | Vocaloid 圈听众 / 同人创作者 | 「这人做过什么，值得关注吗」 |
| 2 | 潜在合作方（作曲、词、曲绘、动画） | 「作品质量如何，怎么联系」 |
| 3 | **以前动漫剪辑时的粉丝** | 「当年那个剪辑作者现在还在做吗」 |
| 4 | 国内泛二次元听众 | 「二创好不好看，能不能一键播放」 |

> 第3 类观众是**回流流量**的主要来源。他们可能不认识现在的你，但认得出你以前的作品。
> 因此 WORKS 页的二创分类与「全部制作 / 部分制作」标记对他们尤其重要——
> 「全部制作」是最强的信任信号。

### 1.4 站点基调

不做宣传落地页，不做花哨动效站。定位为**作品档案馆（Archive）**——
访客进来是「看和听」，不是「被营销」。质感参考设定资料集、音乐杂志版面、乐评网站。

## 2. 设计风格总结

### 2.1 风格关键词

> 提炼自设定图上的自设关键词：`White / Black / Dark / Music / Red / Shine`

| 关键词 | 含义 | 在设计中的落地 |
|---|---|---|
| **White** | 主体留白 | 大面积负空间，页面呼吸感 |
| **Black** | 硬边黑色 | 纯黑 `#08080A`，文字与分割线 |
| **Dark** | 暗部厚重 | 深灰阶层次，图片去饱和处理 |
| **Music** | 音乐性 | ECG 波形线贯穿全站，等宽字体标注 BPM/调性 |
| **Red** | 唯一彩色 | 强调色，只用在交互状态 |
| **Shine** | 白色高光溢出 | 文字发光、图片边缘光、hover 微光 |

补充意象关键词：**終焉**（终结）、**煌めき**（闪耀）、**破軍星**（白虎座凶星）、**キメラ**（性别设定）、**ゴシック**（哥特街头机能）。

**站点个性签名（sig）**

> **「終焉は、最も美しく煌めく。」**
> （終焉は、最も美しく煌めく。）

这条签名贯穿全站：Footer、404 页、TEXT OF THE TOP 首屏文案、SHARE 卡片。
它是「終焉」与「煌めき」两个意象的收束——最华丽的终点。

### 2.2 硬性约束

> **禁止蓝紫配色。** 不出现任何蓝、靛、青、紫色相及其渐变。
> 允许的彩色只有红，且红色仅用于交互反馈，不做大面积铺色。

### 2.3 核心视觉符号

从 LOGO 与设定图提取三个反复出现的符号：

**① 断裂圆环（Broken Ring）**
LOGO 中被上下两段弧切开的圆。主识别符号。
用法：页面转场、加载进度、图片裁切遮罩、hover 时弧段旋转张开。

**② ECG 波形线（心电波）**
设定图右下角 RIPJune 文字旁的波形线。
用法：全站分隔线、时间轴、音频播放进度、Footer 签名。

**③ 斜切 −18°**
LOGO 中 RIPJUNE 字样的倾斜角度。
用法：标题、标签、按钮的文字倾斜，与水平正文形成张力。

### 2.4 排版骨架

设定图的信息排版是全站范式，**每个页面页首统一使用**：

```
RIPJune                        ← 极粗黑体 · 斜切 −18° · 字间距拉开
破軍星の終焉煌めき              ← 明朝体 · 竖排 · 从右向左
ほんんせい。                     ← 极小字号 · 字间距极大 · 低对比

Vocaloid
Music Creator
mekichann                      ← 极小无衬线 · 逐行堆叠 · 元数据
```

### 2.5 图片处理

| 类型 | 处理 |
|---|---|
| 角色立绘、设定图 | 保持灰阶，`filter: grayscale(1)` 统一色调 |
| 作品封面（bilibili 截帧） | 灰度常态；hover 时浮现极淡红色调 |
| LOGO / 头像 | 保持原样黑白，不做灰度处理 |
| 内嵌播放器 iframe | 默认 `grayscale(1)`，hover 恢复彩色 |
| 全站 | 图片统一加极细边框（1px 半透明白），像贴在设定页上的照片 |

## 4. 设计系统

### 4.1 色彩

> 灰阶为主，红色仅作交互反馈。**无蓝无紫。**

#### 基础灰阶（明→暗）

| Token | 值 | 用途 |
|---|---|---|
| `--c-white` | `#FFFFFF` | 页面底色（默认亮色）、反色文字 |
| `--c-gray-100` | `#F2F2F3` | 分区块背景 |
| `--c-gray-200` | `#D8D8DC` | 分割线、次要边框 |
| `--c-gray-300` | `#A8A8B0` | 占位文字、禁用态 |
| `--c-gray-400` | `#6E6E78` | 辅助说明文字 |
| `--c-gray-600` | `#3A3A42` | 次级面板背景 |
| `--c-gray-800` | `#1A1A1E` | 深色区块背景 |
| `--c-black` | `#08080A` | **页面主墨色**、正文 |
| `--c-ink` | `#000000` | 纯黑，仅用于 LOGO 与极端对比 |

#### 强调红

| Token | 值 | 用途 |
|---|---|---|
| `--c-red` | `#CE1126` | **唯一强调色** |
| `--c-red-dim` | `#8E0C1B` | 红色悬停/按下 |
| `--c-red-glow` | `rgba(206,17,38,.28)` | 红色光晕、focus ring |

#### 用法纪律

- 红色**只**用于：链接 hover、当前导航项、播放按钮、focus ring、正在播放的波形进度
- 红色**不**用于：大面积背景、标题文字、装饰色块
- hover 时红色只出现在**细线条和小图标**上，不整块翻红

### 4.2 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| **Display** | `Archivo Black` / `Anton` | RIPJune、页面大标题，斜切 −18° |
| **JP Mincho** | `Shippori Mincho` / `Noto Serif JP` | 破軍星の終焉煌めき、竖排日文 |
| **CN** | `Noto Sans SC` | 中文正文 |
| **EN** | `Inter` | 英文正文、元数据 |
| **Mono** | `JetBrains Mono` | BPM、调性、时间戳、ID 等标注 |

**处理原则**
- Display 字体必须 `transform: rotate(-18deg)` 或 `skewX(-18deg)`
- 日文标题用 `writing-mode: vertical-rl` 竖排
- 极小字号元数据 `10–11px` + `letter-spacing: .3em` 全大写
- 中文正文 `line-height: 1.9`

### 4.3 间距与栅格

- 基础单位 `8px`，全部间距取 8 的倍数
- 桌面端 12 列栅格，最大内容宽 `1280px`，左右留白 `48px`
- 平板 8 列，移动 4 列
- 区块垂直间距 `120px`（桌面）/ `72px`（移动）
- 圆角统一 `2px`（近乎直角，呼应设定图的硬边分割线）

### 4.4 图形元素

| 元素 | 规格 |
|---|---|
| **断裂圆环** | SVG，2 段弧，缺口 `120°`，线宽 `2px`，hover 时旋转 `90°` |
| **ECG 波形** | SVG path，周期 `240px`，线宽 `1.5px`，用作分隔与签名 |
| **分割线** | `1px` 实线 `--c-gray-200` |
| **分割号** | 文字 `—` 或 `/`，作为标题与内容的连接符 |
| **角标** | 右上角小方块，标注作品编号（如 `NO.004`） |

### 4.5 响应式断点

| 断点 | 宽度 | 处理 |
|---|---|---|
| 桌面 | `≥1280px` | 完整栅格，竖排日文显示 |
| 平板 | `768–1279px` | 8 列，竖排日文转横排 |
| 移动 | `<768px` | 4 列，单栏，LOGO 斜切减小到 −12° |

## 5. 动效规范

> 原则：**动而不炫技。** 简洁中显高级。
> 动效分四个落点：**背景、顶部标签栏、正文卡片、鼠标**。
> 每处只做一件事，用最轻的方式做。

### 5.1 四类动效的分工

| 落点 | 作用 | 频率 | 强度 |
|---|---|---|---|
| **背景动效** | 让页面「有生命」 | 常驻循环 | 极低，几乎察觉不到 |
| **顶部标签栏动效** | 指示当前位置 | 交互触发 | 中，快速明确 |
| **正文卡片动效** | 分隔内容 + 悬停反馈 | 滚动触发 + 悬停 | 中低 |
| **鼠标动效** | 制造「在场感」 | 跟随指针 | 低，只在局部 |

**通用约束**
- 缓动统一 `cubic-bezier(.16,1,.3,1)`（起步快、收尾极缓）
- 入场 `480ms` · 交互 `240ms` · 背景循环 `≥20s`
- **禁止**：弹跳、缩放超过 `1.05`、旋转超过 `10°`、粒子/光斑跟随、视差滚动
- 所有动效在 `prefers-reduced-motion: reduce` 下关闭

---

### 5.2 背景动效

背景不是静止的，但**必须慢到几乎察觉不到**——观众说不出它在动，只觉得「页面是活的」。

####① ECG 底纹（全局，最重要）

- 页面最底层铺一层 **1px 灰阶 ECG 波形**（`--c-gray-200`，透明度 `.35`）
- 波形**横向极缓慢平移**：`60s` 循环，移动距离 = 一个波形周期
- 这是全站动效的基调来源——呼应设定图的心电波
- **不可**加红色、不发光、不随鼠标变化

#### ② 断裂圆环·背景版（仅 TOP / ARCHIVE）

- 一个直径 `min(90vw, 900px)` 的巨大断裂圆环，`1px` 线宽，透明度 `.06`
- 置于页面背景，两段弧**各自缓慢自转**：`120s` / `160s` 一圈（比首屏那个更慢）
- 作为背景纹理存在，**不响应鼠标**

#### ③ 纸面颗粒（静态）

- 全站叠一层极淡噪点纹理（SVG feTurbulence生成，`opacity .025`）
- **完全静态**，用于消除大面积纯白的塑料感，让白底「像纸」
- 这是质感的关键，成本极低

#### ④ 红色呼吸点（仅 TOP 首屏）

- ECG 波形上有一个 `2px` 的红点，沿波形缓慢移动，`9s` 循环一圈
- 出现频率极低，作用是让视线有落点

---

### 5.3 顶部标签栏动效

WORKS 页的分类标签栏是全站最重要的导航，动效分三段。

#### ① 当前项指示器（切换时）

```
ALL 8 ────二创剪辑 7 ──── 原创曲 0 ──── Vocaloid 歌唱 1
        ▔▔▔▔
```

- 切换标签时，**红色下划线**从旧项底部滑向新项
- 时长 `320ms`，`cubic-bezier(.16,1,.3,1)`
- 用一条绝对定位的 `<span>` 移动 + `width` 过渡，**不做逐项淡入淡出**（那样很廉价）

#### ② 悬停：波形延长

- 悬停某个未选中标签时，其下方的**灰阶波形线**从 `24px` 延长到 `48px`
- 同时该标签的波形**加深一档**（`--c-gray-300` → `--c-gray-600`）
- 时长 `240ms`

#### ③ 标签计数呼吸

- 每个标签右侧的数字（`7`）用等宽字体
- 切换分类时数字做一次**极短的缩放脉冲**：`scale(1) → 1.12 → 1`，`260ms`
- 只在数字上做，不影响标签文字

#### ④ 顶部 Header

- 滚动超过 `80px` 时高度从 `64px` 收到 `48px`
- 底部1px 分割线淡入
- 语言切换器 hover：下划线从左推进

---

### 5.4 正文卡片动效

正文内容**切分为卡片**——这是本站排版的核心手法（呼应设定资料集把信息贴在版面上的感觉）。

#### 卡片基础样式

```
┌─────────────────────────────────────┐
│ NO.001                全部制作       │  ← 顶栏：编号 + 参与度
│                                     │
│  标题文字                           │  ← 正区
│                                     │
│  ─────                              │  ← 底部ECG 细线
│  圆桌动漫 · 2026-05-03 · 1.2w 播放   │  ← 元数据行
└─────────────────────────────────────┘
```

- 底色 `--c-white`，1px 边框 `--c-gray-200`
- **无阴影**（阴影 = 廉价）、**无圆角**（2px 呼应硬边）
- 内部留白 `24px` / `32px`
- 卡片之间间距 `24px`

#### ① 滚动入场

- 卡片进入视口时：`opacity 0 → 1` + `translateY(20px) → 0`
- 时长 `480ms`
- **同组卡片依次延迟 `70ms`**（最多 6 张后不再累加）
- 卡片内元素一起动，**不做内部元素的分层飞入**（太花）

#### ② 悬停：卡片响应

| 元素 | 变化 | 时长 |
|---|---|---|
| 卡片整体 | `border-color` → `--c-black`，向右位移 `4px` | `240ms` |
| 封面图 | `grayscale(1) → .15` | `240ms` |
| 底部 ECG 线 | 从左向右**重新描画一次**（`stroke-dashoffset` 动画） | `420ms` |
| 标题 | 下划线从左推进 | `240ms` |
| 播放键 | 细线三角展开成实心 | `200ms` |

> 卡片位移 `4px` 而非 `scale`——位移比缩放克制，也不会让边框变形。

#### ③ 卡片序号

- `NO.001` 等宽字体贴在卡片右上
- 悬停时数字**颜色由灰变黑**（`--c-gray-400` → `--c-black`），不做位移

### 5.5 鼠标动效

**不做自定义光标**（`cursor: url()` 在跨平台和移动端都不可靠）。
改用「局部响应」——鼠标经过时，**那一块区域**有反应。

#### ① 内容区·光标牵引细线（全局，签名动效）

- 鼠标移动时，其后拖一条**1px 红线**，长度 `56px`
- 线是 SVG path，两点跟随指针，带 `140ms` 延迟跟随（不是死跟，略有滞后感）
- 鼠标停下时线自然收回消失
- **仅在内容区**（`.content` 容器内）生效，Header/Footer 不生效
- 鼠标移出内容区即隐藏

> 这就是「鼠标的特效」——不是换指针样式，而是指针**拖尾**。

#### ② 卡片磁性微吸（仅 WORKS 卡片）

- 鼠标进入卡片时，卡片内容层向鼠标方向**位移最多 `6px`**
- 位移量 = `(鼠标位置 − 卡片中心) × 0.02`，并被`6px` 截断
- 移出时`240ms` 弹回原位
- 位移的是**内容层**（标题+图），卡片边框不动——产生「内容浮在卡上」的层次

#### ③ 断裂圆环·开合

- 鼠标进入断裂圆环元素时，两段弧**各向外旋转 `42°`**，缺口张开
- 时长 `420ms`，`--c-red` 变红
- 离开时收回

#### ④ 文字·下划线推进

- 所有链接 hover：下划线从左推进，`240ms`
- 元数据项（年份、编号）hover：数字**后移 `2px`**

#### ⑤ 指针位置反馈点（仅 ARCHIVE 灯箱）

- 灯箱打开时，左右两侧出现**红点 + 「PREV」「NEXT」文字**
- hover 时红点放大 `1.4`，文字右移 `4px`

---

### 5.6 「不显得廉价」的五条底线

1. **所有循环动效周期 ≥ 20s**——快 =廉价
2. **同时出现的动效元素 ≤ 3处**——满屏动 = 廉价
3. **位移距离 ≤ 8px，缩放 ≤ 1.05**——大幅运动 = 廉价
4. **错落时序**——标题先、正文延迟 `80ms`、卡片间 `70ms`；同时出现 = 廉价
5. **缓动只用一个**——`cubic-bezier(.16,1,.3,1)`，不要 ease-in 也不要 linear

---

### 5.7 无障碍与降级

- `prefers-reduced-motion: reduce`：**全部动效关闭**，内容直接可见
- 背景 ECG、圆环自转用 CSS `animation`，reduced-motion 下 `animation: none`
- 鼠标牵引线用 JS 监听 `pointermove`，reduced-motion 下不挂载
- 环境动效在 `document.hidden` 时 `animation-play-state: paused`
- 移动端（触摸设备）**完全禁用**鼠标牵引线与磁性吸附

| 项 | 要求 |
|---|---|
| **尺寸** | `1200 × 630 px`（唯一稳定支持的尺寸） |
| **比例** | 约 `1.91:1` |
| **格式** | `PNG` 或 `JPG`，文件大小 **< 300KB**（超出会被部分平台丢弃） |
| **文件位置** | 仓库 `public/og-image.jpg`，线上路径 `https://<域名>/og-image.jpg` |
| **在HTML 中的声明** | 每页`<head>` 内都要有（见下方代码） |

```html
<!-- 每页 head 里都要写全这四行 -->
<meta property="og:type"        content="website" />
<meta property="og:title"       content="RIPJune — Vocaloid Music Creator" />
<meta property="og:description" content="破軍星の終焉煌めき / メキチャン。二创剪辑与 Vocaloid 歌唱。" />
<meta property="og:image"       content="https://rftgcftctchcg.github.io/hagunseinoshuuenkirameki/og-image.jpg" />
<meta property="og:url"         content="https://rftgcftctchcg.github.io/hagunseinoshuuenkirameki/" />
```

**补充建议**
- 再加 `twitter:card` = `summary_large_image`，让 X 也显示大图
- 中/日/英三语页可以用**不同的 og:title文字**，但**共用同一张图**（省事，且视觉一致）
- `og:description` 控制卡片文案，约 **60–120 字符**，超出会被截断

#### 设计要求（沿用本站视觉规范）

- **背景**：`--c-white` 纯白，或反过来做一张 `--c-black` 的「暗色款」
- **主视觉**：断裂圆环 + 斜切 RIPJUNE（与 LOGO 同一套元素）
- **必备文字**：`RIPJune` + `終焉は、最も美しく煌めく。`
- **辅助信息**：三行小字 `Vocaloid Music Creator` / `メキチャン` / `破軍星の終焉煌めき`
- **底部**：一条 ECG 波形线（呼应全站符号）
- **禁止**：蓝紫配色、大面积红底、超过两种字体
- 文字要留足安全边距（各边 ≥ `80px`），因为部分平台会裁掉边缘

## 8. 技术栈与部署

| 项目 | 选择 | 理由 |
|---|---|---|
| 构建 | **Astro** | 静态输出、极快、适合作品站 |
| 样式 | 原生 CSS + 自定义属性 | 无框架负担，完全控制灰阶与红色调 |
| 三语 | Astro i18n 集合 | 构建期生成三份静态页，零运行时开销 |
| 字体 | Google Fonts | Archivo Black / Shippori Mincho / Noto Sans SC / Inter / JetBrains Mono |
| 动画 | CSS + IntersectionObserver | 无动画库，动效需求简单可控 |
| 波形 | 手写 SVG path | 轻量、可控、风格统一 |
| 部署 | GitHub Pages | 仓库已就绪，push 即上线 |

### 8.1 目录结构（规划）

### 8.2 可访问性

- 语义化标签：`header` / `nav` / `main` / `section` / `article` / `footer`
- 每页唯一 `h1`，图片全带 `alt`
- 键盘可达：灯箱支持 ESC/方向键，focus 可见红色 ring
- 对比度：`#08080A` on `#FFFFFF` = **19.9:1**，远超 AA
- `prefers-reduced-motion` 下关闭所有动效

### 8.3 三语实现

- 语言切换器存 `localStorage`，无则读 `Accept-Language`
- 路径：`/`（日）· `/zh/`（中）· `/en/`（英）
- 字体随语言切换（日文用明朝体，中英文用无衬线）
- 右上周定切换入口，移动端收进汉堡菜单
