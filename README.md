## 1. 项目定位

### 1.1 这是什么

一个 **VOCALOID Music Creator（二创剪辑作者）** 的个人官方网站。

三条身份主线，在网站上并列呈现：

| 身份 | 日文 / 表述 | 说明 |
|---|---|---|
| 主身份 | **VOCALOID Music Creator** | 站点的核心，权重最高 |
| 副身份 | **二创剪辑作者** | 你过去的积累，有大爆作，是引流主力 |
| 虚拟角色 | **Chimera（合成兽）** | 破軍星の終焉煌めき，视觉与叙事的载体 |

### 1.2 目标

- **短期**：把已有的二创爆作沉淀成一个能长期挂着的作品档案，替代散落的平台主页
- **长期**：以 VOCALOID Music Creator 的身份接到稳定的合作与委托

### 1.3 目标观众

| 优先级 | 人群 | 他们想找什么 |
|---|---|---|
| 1 | Vocaloid 圈听众 / 同人创作者 | 「这人做过什么，值得关注吗」 |
| 2 | 潜在合作方（作曲、词、曲绘、动画） | 「作品质量如何，怎么联系」 |
| 3 | 国内泛二次元听众 | 「二创好不好看，能不能一键播放」 |

### 1.4 站点基调

不做宣传落地页，不做花哨动效站。定位为**作品档案馆（Archive）**——
访客进来是「看和听」，不是「被营销」。质感参考设定资料集、音乐杂志版面、乐评网站。

## 2. 设计风格总结

### 2.1 风格关键词

> 提炼自设定图上的自设关键词：`White / Black / Dark / Music / Red / Shine`

| 关键词 | 含义 | 在设计中的落地 |
|---|---|---|
| **White** | 主体留白 | 大面积负空间，页面呼吸感 |
| **Black** | 硬边黑色 | 纯黑 `#08080A`，文字与分割线 |
| **Dark** | 暗部厚重 | 深灰阶层次，图片去饱和处理 |
| **Music** | 音乐性 | ECG 波形线贯穿全站，等宽字体标注 BPM/调性 |
| **Red** | 唯一彩色 | 强调色，只用在交互状态 |
| **Shine** | 白色高光溢出 | 文字发光、图片边缘光、hover 微光 |

补充意象关键词：**終焉**（终结）、**煌めき**（闪耀）、**破軍星**（白虎座凶星）、**Chimera**（多声源合成兽）、**ゴシック**（哥特街头机能）。

### 2.2 硬性约束

> **禁止蓝紫配色。** 不出现任何蓝、靛、青、紫色相及其渐变。
> 允许的彩色只有红，且红色仅用于交互反馈，不做大面积铺色。

### 2.3 核心视觉符号

从 LOGO 与设定图提取三个反复出现的符号：

**① 断裂圆环（Broken Ring）**
LOGO 中被上下两段弧切开的圆。这是主识别符号。
用法：页面转场、加载进度、图片裁切遮罩、hover 时弧段旋转张开。

**② ECG 波形线（心电波）**
设定图右下角 RIPJune 文字旁的波形线。
用法：作为全站分隔线、时间轴、音频播放进度、页面底部签名。

**③ 斜切 −18°**
LOGO 中 RIPJUNE 字样的倾斜角度。
用法：标题、标签、按钮的文字倾斜，与水平正文形成张力。

### 2.4 排版骨架

设定图的信息排版是全站范式：

```
RIPJune                        ← 极粗黑体 · 斜切 −18° · 字间距拉开
破軍星の終焉煌めき← 明朝体 · 竖排 · 从右向左
ほんんせい。                     ← 极小字号 · 字间距极大 · 低对比

Vocaloid
Music Creator
Chimera                        ← 极小无衬线 · 逐行堆叠 · 作为元数据
```

**这个「巨大的英文斜体标题 + 竖排日文 + 极小的元数据列表」三段式，将作为每个页面页首的统一格式。**

### 2.5 图片处理

| 类型 | 处理 |
|---|---|
| 角色立绘、设定图 | 保持灰阶，`filter: grayscale(1)` 统一色调 |
| 作品封面 | 灰度常态；hover 时短暂浮现极淡红色调 |
| LOGO / 头像 | 保持原样黑白，不做灰度处理 |
| 全站 | 图片统一加极细边框（1px半透明白），像贴在设定页上的照片 |

## 3. 信息架构（页面清单）

### 3.1 站点地图

采用**多页独立站点**结构，共 **6 个页面 + 404**。

```
/                    TOP          视觉冲击 + 精选内容
├── /profile         PROFILE      你是谁
├── /works           WORKS        所有作品（核心）
│   └── /works/:id   WORK DETAIL  单个作品详情（含致谢栏）
├── /archive         ARCHIVE      角色设定档案
├── /social          SOCIAL社交与联系
└── /404             NOT FOUND    断链兜底
```

### 3.2 页面职责一览

| # | 页面 | 路径 | 一句话职责 | 权重 |
|---|---|---|---|---|
| 1 | **TOP** | `/` | 用一屏说清「我是谁」，再往下就是精选内容 | ★★★ |
| 2 | **PROFILE** | `/profile` | 立绘 + 个人介绍 + 技能标签 + 合作意向 | ★★☆ |
| 3 | **WORKS** | `/works` | **站点核心**，按身份分区的作品档案 | ★★★ |
| 4 | **WORK DETAIL** | `/works/:id` | 单个作品的完整信息与播放/嵌入 + 致谢栏 | ★★☆ |
| 5 | **ARCHIVE** | `/archive` | 角色设定拆解，从设定图分块展开 | ★★☆ |
| 6 | **SOCIAL** | `/social` | 平台入口 + 商务联系 | ★☆☆ |
| — | **404** | `/404` | 断链兜底，风格化 | — |

### 3.3 全站导航

**顶部导航（Header）**：固定在顶部，滚动时收窄。

- Logo 简化为「断裂圆环 + RIPJune」小图标，点击回 TOP
- 语言切换器常驻右上
- 移动端折叠为汉堡菜单

**底部（Footer）**：全站统一

## 4. 设计系统

### 4.1 色彩

> 灰阶为主，红色仅作交互反馈。**无蓝无紫。**

#### 基础灰阶（明→暗）

| Token | 值 | 用途 |
|---|---|---|
| `--c-white` | `#FFFFFF` | 页面底色（默认亮色）、反色文字 |
| `--c-gray-100` | `#F2F2F3` | 分区块背景 |
| `--c-gray-200` | `#D8D8DC` | 分割线、次要边框 |
| `--c-gray-300` | `#A8A8B0` | 占位文字、禁用态 |
| `--c-gray-400` | `#6E6E78` | 辅助说明文字 |
| `--c-gray-600` | `#3A3A42` | 次级面板背景 |
| `--c-gray-800` | `#1A1A1E` | 深色区块背景 |
| `--c-black` | `#08080A` | **页面主墨色**、正文 |
| `--c-ink` | `#000000` | 纯黑，仅用于 LOGO 与极端对比 |

#### 强调红

| Token | 值 | 用途 |
|---|---|---|
| `--c-red` | `#CE1126` | **唯一强调色** |
| `--c-red-dim` | `#8E0C1B` | 红色悬停/按下 |
| `--c-red-glow` | `rgba(206,17,38,.28)` | 红色光晕、focus ring |

#### 用法纪律

- 红色**只**用于：链接 hover、当前导航项、播放按钮、focus ring、正在播放的波形进度
- 红色**不**用于：大面积背景、标题文字、装饰色块
- hover 时红色只出现在**细线条和小图标**上，不整块翻红

### 4.2 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| **Display** | `Archivo Black` / `Anton`（无衬线极粗） | RIPJune、页面大标题，斜切 −18° |
| **JP Mincho** | `Shippori Mincho` / `Noto Serif JP`（明朝体） | 破軍星の終焉煌めき、竖排日文 |
| **CN** | `Noto Sans SC`（无衬线） | 中文正文 |
| **EN** | `Inter`（无衬线） | 英文正文、元数据 |
| **Mono** | `JetBrains Mono` | BPM、调性、时间戳、ID 等标注 |

**处理原则**：
- Display 字体必须 `transform: rotate(-18deg)` 或 `skewX(-18deg)`
- 日文标题用 `writing-mode: vertical-rl` 竖排
- 极小字号元数据 `10–11px` + `letter-spacing: .3em` 全大写
- 中文正文 `line-height: 1.9`，不追求紧凑

### 4.3 间距与栅格

- 基础单位 `8px`，全部间距取 8 的倍数
- 桌面端 12 列栅格，最大内容宽 `1280px`，左右留白 `48px`
- 平板 8 列，移动 4 列
- 区块垂直间距 `120px`（桌面）/ `72px`（移动）
- 圆角统一 `2px`（近乎直角，呼应设定图的硬边分割线）

### 4.4 图形元素

| 元素 | 规格 |
|---|---|
| **断裂圆环** | SVG，2 段弧，缺口 `120°`，线宽 `2px`，hover 时旋转 `90°` |
| **ECG 波形** | SVG path，周期 `240px`，线宽 `1.5px`，用作分隔与签名 |
| **分割线** | `1px` 实线 `--c-gray-200`，暗色模式下 `--c-gray-600` |
| **分割号** | 文字 `—` 或 `/`，作为标题与内容的连接符 |
| **角标** | 右上角小方块，标注作品编号（如 `NO.004`） |

### 4.5 交互原则

- **克制**：只有 hover 下划线推进、圆环旋转、图片去灰度转色三种主动效
- **无自动轮播**，无入场动画堆叠
- 滚动时导航收窄为 `64px → 48px`
- 图片 hover：`grayscale(1) → grayscale(.2)` + 极淡红光晕
- 所有过渡 `cubic-bezier(.22,.61,.36,1)`，`240ms`
- 尊重 `prefers-reduced-motion`

### 4.6 响应式断点

| 断点 | 宽度 | 处理 |
|---|---|---|
| 桌面 | `≥1280px` | 完整栅格，竖排日文显示 |
| 平板 | `768–1279px` | 8 列，竖排日文转横排 |
| 移动 | `<768px` | 4 列，单栏，LOGO 斜切减小到 −12° |

## 5. 各页面详细设计

### 5.1 TOP `/`

**第一屏（100vh，视觉先行）**

布局：
```
┌──────────────────────────────────────────┐
│  〔右上：斜切小字元数据〕                  │
│                                          │
│         ▟▙  断裂圆环（缓慢旋转）           │
│        RIPJUNE                            │
│   ── 破軍星の終焉煌めき（竖排，靠右）       │
│                                          │
│  Vocaloid Music Creator                   │
│  Chimera                                 │
│                                          │
│  ▁▂▅▇▅▂▁  ECG 波形线                      │
│  [ WORKSPACE ]  ← 向下箭头提示滚动          │
└──────────────────────────────────────────┘
```

- **背景**：纯白 → 底部渐变到 `--c-gray-100`
- **断裂圆环**：直径 `min(52vw, 560px)`，作为 RIPJUNE 字样的容器，两段弧线持续缓慢反向旋转（`40s` / `55s` 一圈）
- **RIPJUNE**：Display 字体，斜切 −18°，字号 `clamp(3rem, 12vw, 11rem)`，字间距 `0.05em`
- **破軍星の終焉煌めき**：竖排明朝体，位于 RIPJUNE 右侧，`letter-spacing: .25em`
- **元数据**：`Vocaloid Music Creator` / `Chimera`，`11px`，`letter-spacing: .3em`，右上角对齐
- **ECG 波形**：横贯底部 `80%` 宽度，透明度 `0.4`

**第二屏（精选作品）**

- 区块标题：`SELECTED WORKS` + 竖排日文 `精选作品`
- 3–4 部精选作品的**大图错落排布**（非等分网格），每张图右下角有 `NO.00X` 角标
- hover：图去灰度、圆环角标展开、标题下划线从左推进
- 底部：`ALL WORKS →` 链接到 `/works`

**第三屏（身份速览）**

三列并排，用分割线隔开：

| | 日文 | 说明 |
|---|---|---|
| **01** | 二创剪辑 | 过往的大爆作品积累 |
| **02** | Vocaloid Music Creator | 现在的主身份 |
| **03** | Chimera | 角色与概念 |

每列下方一行小字英文说明 + 作品数量。

**第四屏（RSS / 最新动态）**

- 最近 3 条更新，以「日期 + 标题」列表形式，像设定资料集的变更记录
- 底部进入 Footer

### 5.2 PROFILE `/profile`

**结构**

```
① 页首（大标题区）
   PROFILE ─ 斜切 Display
   プロフィール ─ 竖排明朝体靠右
   Profile / Profile ─ 极小元数据

② 立绘区
   头像 + 半身立绘（灰度处理）
   断裂圆环作为头像外框

③ 个人介绍
   日文 + 中文 + 英文 三段（对应三语系统）

④ SKILLS 标签墙
   剪辑 / 调音 / 编曲 / 混音 / 曲绘 / 动画 / 日语 / 吉他 / 钢琴 …

⑤ 统计数字（等宽字体）
   作品数 / 播放量 / 关注者数 / 合作数

⑥ 合作意向
   「正在寻找」与「可提供」两个列表

⑦ 跳转 CTA
   → 前往 WORKS   → 前往 SOCIAL
```

**立绘处理**
- 使用设定图左侧的全身立绘，裁切成半身
- `filter: grayscale(1) contrast(1.05)`
- 背后叠一个 `300px` 的断裂圆环 SVG，线宽 `1px` 透明度 `0.3`

**三语介绍的处理方式**

不用 Tab 切换，**三段同时纵向排列**：

```
── PROFILE ─────────────────────────

【日本語】
（正文，日文明朝体）

──────

【中文】
（正文）

──────

ENGLISH
(body copy, Inter)
```

这样三种语言同时可见，也符合设定集「全部信息摊开」的排版气质。

### 5.3 WORKS `/works` ★核心页面

**页首**

```
WORKS ─ 斜切 Display
作品 ─ 竖排
Works / Works ─ 元数据
──────
TOTAL 24 WORKS / 3 CATEGORIES
```

**分类切换**

顶部一条横向标签栏，**不是胶囊按钮**，而是用 ECG 波形线连接的文字标签：

```
 ALL 24 ──── VO P SING 8 ──── 二创剪辑 12 ──── 原创曲 4
```

- 当前项：红色 + 上方一小段红色波形
- hover：波形线延长
- 切换时下方内容做 12px 上移淡入

**四个分区（按身份划分）**

| 分类 | 日文 | 标记色 | 内容 |
|---|---|---|---|
| **ALL** | すべて | — | 全部作品 |
| **VO P SING** | VOCALOID歌唱 | 红 | 用他人音源演唱的作品 |
| **二创剪辑** | 二次創作 | 灰 | 剪辑、MAD、PV 类 |
| **原创曲** | オリジナル | 黑 | 自己词曲或参与制作 |

**作品卡片设计**

每张卡片是一个「贴在设定页上的照片」：

```
┌─────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░ │  ← 灰度封面
│ ░░░░░░░░░░░░░░░░░░░░░░ │
│ ░░░░░░░░░░░░░░░░░░░░░░ │        NO.004 ← 右上角标
│                         │  ┌──┐
│                         │  │▶ │              ← 左下播放键
└─────────────────────────┘ └─┴──┘
  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
  曲名标题                     ← hover 显示
  VOCALOID 5.1 · 原创曲        ← 元数据 mono
  2026.03.14                   ← 日期
```

- 默认：封面灰度，`NO.00X` 角标与日期可见，标题隐藏
- hover：封面去灰度、**从底部滑出标题与元数据**、播放键由细线展开成实心三角
- 右下角 `NO.00X` 用等宽字体，是硬边小方块（呼应 LOGO 的角标感）
- 网格：桌面 3 列，平板 2 列，移动 1 列
- 卡片之间**无阴影**，仅 1px 分割线，靠留白分隔

**筛选（次要功能，右上角）**

- 年份筛选
- 音源筛选（VOCALOID / UTAU / 其他）
- 收起为一个 `[ FILTER ]` 细线按钮，展开为下拉

**空状态**

筛选无结果时，显示断裂圆环 SVG + `NO SIGNAL`，呼应心电波的意象。

## 8. 技术栈与部署

### 8.1 技术选型

| 项目 | 选择 | 理由 |
|---|---|---|
| 构建 | **Astro** | 静态输出、极快、适合作品站 |
| 样式 | 原生 CSS + 自定义属性 | 无框架负担，完全控制灰阶与红色调 |
| 三语 | Astro i18n 集合 | 构建期生成三份静态页，零运行时开销 |
| 字体 | Google Fonts | Archivo Black / Shippori Mincho / Noto Sans SC / Inter / JetBrains Mono |
| 图片 | 原生 `<img>` + CSS filter | 灰度处理无需构建期处理 |
| 波形 | 手写 SVG path | 轻量、可控、风格统一 |
| 搜索 | 客户端过滤（无后端） | 作品量不需要 Algolia |
| 部署 | GitHub Pages | 仓库已就绪，push 即上线 |

### 8.2 为什么选 Astro

- 作品站需要 SEO 和静态化，Astro 输出纯 HTML
- 三语可以构建期静态化，不依赖客户端 JS
- 「拒绝蓝紫」的严格视觉规范，用原生 CSS 比框架更不容易失控
- 未来若要加 RSS / sitemap，Astro 有现成集成

### 8.3 目录结构（规划）

```
/
├── public/
│   ├── logo.svg
│   ├── avatar.png
│   └── works/
├── src/
│   ├── components/    # Ring, WaveLine, WorkCard, SectionTitle...
│   ├── layouts/       # BaseLayout（含 Header/Footer）
│   ├── pages/
│   │   ├── index.astro
│   │   ├── profile.astro
│   │   ├── works/index.astro
│   │   ├── works/[id].astro
│   │   ├── archive.astro
│   │   ├── social.astro
│   │   └── 404.astro
│   ├── styles/        # tokens.css, base.css
│   └── data/          # works.ts, profile.ts, archive.ts, social.ts
└── astro.config.mjs
```

### 8.4 响应式与可访问性

- 语义化标签：`header` / `nav` / `main` / `section` / `article` / `footer`
- 每页唯一 `h1`，图片全带 `alt`
- 键盘可达：灯箱支持 ESC/方向键，focus 可见红色 ring
- 对比度：正文 `#08080A` on `#FFFFFF` = 19.9:1，远超 AA
- `prefers-reduced-motion` 下关闭旋转与滑动

### 8.5 三语实现

- 语言切换器存 `localStorage`，无则读浏览器 `Accept-Language`
- 路径方案：`/`（日）`/zh/`（中）`/en/`（英）
- 字体随语言切换（日文用明朝体，中英文用无衬线）
- 页面右上固定切换入口，移动端收进汉堡菜单
