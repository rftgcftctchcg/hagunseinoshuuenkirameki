## 1. 项目定位

### 1.1 这是什么

一个 **VOCALOID Music Creator / 二创剪辑作者** 的个人官方网站。

三条身份主线，在网站上并列呈现：

| 身份 | 表述 | 说明 |
|---|---|---|
| 主身份 | **Vocaloid Music Creator** | 站点核心，权重最高 |
| 副身份 | **二创剪辑作者** | 过往积累，有大爆作，是引流主力 |
| 虚拟角色 | **メキチャン（mekichann）** | 破軍星の終焉煌めき，视觉与叙事载体 |

> **命名约定（重要）**
> 角色自设名为 **メキチャン（mekichann）**。
> **キメラ（kimera）** 是角色的**性别**设定，源自重音テト的性别，亦代表本人中性。
> 两者不可混用：名称用「メキチャン」，性别用「キメラ」。
> 英文/罗马音一律写 **mekichann**，不写 chimera。

### 1.2 目标

- **短期**：把已有的二创爆作沉淀成一个能长期挂着的作品档案，替代散落的平台主页
- **长期**：以 Vocaloid Music Creator 的身份接到稳定的合作与委托

### 1.3 目标观众

| 优先级 | 人群 | 他们想找什么 |
|---|---|---|
| 1 | Vocaloid 圈听众 / 同人创作者 | 「这人做过什么，值得关注吗」 |
| 2 | 潜在合作方（作曲、词、曲绘、动画） | 「作品质量如何，怎么联系」 |
| 3 | **以前动漫剪辑时的粉丝** | 「当年那个剪辑作者现在还在做吗」 |
| 4 | 国内泛二次元听众 | 「二创好不好看，能不能一键播放」 |

> 第3 类观众是**回流流量**的主要来源。他们可能不认识现在的你，但认得出你以前的作品。
> 因此 WORKS 页的二创分类与「全部制作 / 部分制作」标记对他们尤其重要——
> 「全部制作」是最强的信任信号。

### 1.4 站点基调

不做宣传落地页，不做花哨动效站。定位为**作品档案馆（Archive）**——
访客进来是「看和听」，不是「被营销」。质感参考设定资料集、音乐杂志版面、乐评网站。

## 2. 设计风格总结

### 2.1 风格关键词

> 提炼自设定图上的自设关键词：`White / Black / Dark / Music / Red / Shine`

| 关键词 | 含义 | 在设计中的落地 |
|---|---|---|
| **White** | 主体留白 | 大面积负空间，页面呼吸感 |
| **Black** | 硬边黑色 | 纯黑 `#08080A`，文字与分割线 |
| **Dark** | 暗部厚重 | 深灰阶层次，图片去饱和处理 |
| **Music** | 音乐性 | ECG 波形线贯穿全站，等宽字体标注 BPM/调性 |
| **Red** | 唯一彩色 | 强调色，只用在交互状态 |
| **Shine** | 白色高光溢出 | 文字发光、图片边缘光、hover 微光 |

补充意象关键词：**終焉**（终结）、**煌めき**（闪耀）、**破軍星**（白虎座凶星）、**キメラ**（性别设定）、**ゴシック**（哥特街头机能）。

**站点个性签名（sig）**

> **「終焉は、最も美しく煌めく。」**
> （終焉は、最も美しく煌めく。）

这条签名贯穿全站：Footer、404 页、TEXT OF THE TOP 首屏文案、SHARE 卡片。
它是「終焉」与「煌めき」两个意象的收束——最华丽的终点。

### 2.2 硬性约束

> **禁止蓝紫配色。** 不出现任何蓝、靛、青、紫色相及其渐变。
> 允许的彩色只有红，且红色仅用于交互反馈，不做大面积铺色。

### 2.3 核心视觉符号

从 LOGO 与设定图提取三个反复出现的符号：

**① 断裂圆环（Broken Ring）**
LOGO 中被上下两段弧切开的圆。主识别符号。
用法：页面转场、加载进度、图片裁切遮罩、hover 时弧段旋转张开。

**② ECG 波形线（心电波）**
设定图右下角 RIPJune 文字旁的波形线。
用法：全站分隔线、时间轴、音频播放进度、Footer 签名。

**③ 斜切 −18°**
LOGO 中 RIPJUNE 字样的倾斜角度。
用法：标题、标签、按钮的文字倾斜，与水平正文形成张力。

### 2.4 排版骨架

设定图的信息排版是全站范式，**每个页面页首统一使用**：

```
RIPJune                        ← 极粗黑体 · 斜切 −18° · 字间距拉开
破軍星の終焉煌めき              ← 明朝体 · 竖排 · 从右向左
ほんんせい。                     ← 极小字号 · 字间距极大 · 低对比

Vocaloid
Music Creator
mekichann                      ← 极小无衬线 · 逐行堆叠 · 元数据
```

### 2.5 图片处理

| 类型 | 处理 |
|---|---|
| 角色立绘、设定图 | 保持灰阶，`filter: grayscale(1)` 统一色调 |
| 作品封面（bilibili 截帧） | 灰度常态；hover 时浮现极淡红色调 |
| LOGO / 头像 | 保持原样黑白，不做灰度处理 |
| 内嵌播放器 iframe | 默认 `grayscale(1)`，hover 恢复彩色 |
| 全站 | 图片统一加极细边框（1px 半透明白），像贴在设定页上的照片 |

## 4. 设计系统

### 4.1 色彩

> 灰阶为主，红色仅作交互反馈。**无蓝无紫。**

#### 基础灰阶（明→暗）

| Token | 值 | 用途 |
|---|---|---|
| `--c-white` | `#FFFFFF` | 页面底色（默认亮色）、反色文字 |
| `--c-gray-100` | `#F2F2F3` | 分区块背景 |
| `--c-gray-200` | `#D8D8DC` | 分割线、次要边框 |
| `--c-gray-300` | `#A8A8B0` | 占位文字、禁用态 |
| `--c-gray-400` | `#6E6E78` | 辅助说明文字 |
| `--c-gray-600` | `#3A3A42` | 次级面板背景 |
| `--c-gray-800` | `#1A1A1E` | 深色区块背景 |
| `--c-black` | `#08080A` | **页面主墨色**、正文 |
| `--c-ink` | `#000000` | 纯黑，仅用于 LOGO 与极端对比 |

#### 强调红

| Token | 值 | 用途 |
|---|---|---|
| `--c-red` | `#CE1126` | **唯一强调色** |
| `--c-red-dim` | `#8E0C1B` | 红色悬停/按下 |
| `--c-red-glow` | `rgba(206,17,38,.28)` | 红色光晕、focus ring |

#### 用法纪律

- 红色**只**用于：链接 hover、当前导航项、播放按钮、focus ring、正在播放的波形进度
- 红色**不**用于：大面积背景、标题文字、装饰色块
- hover 时红色只出现在**细线条和小图标**上，不整块翻红

### 4.2 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| **Display** | `Archivo Black` / `Anton` | RIPJune、页面大标题，斜切 −18° |
| **JP Mincho** | `Shippori Mincho` / `Noto Serif JP` | 破軍星の終焉煌めき、竖排日文 |
| **CN** | `Noto Sans SC` | 中文正文 |
| **EN** | `Inter` | 英文正文、元数据 |
| **Mono** | `JetBrains Mono` | BPM、调性、时间戳、ID 等标注 |

**处理原则**
- Display 字体必须 `transform: rotate(-18deg)` 或 `skewX(-18deg)`
- 日文标题用 `writing-mode: vertical-rl` 竖排
- 极小字号元数据 `10–11px` + `letter-spacing: .3em` 全大写
- 中文正文 `line-height: 1.9`

### 4.3 间距与栅格

- 基础单位 `8px`，全部间距取 8 的倍数
- 桌面端 12 列栅格，最大内容宽 `1280px`，左右留白 `48px`
- 平板 8 列，移动 4 列
- 区块垂直间距 `120px`（桌面）/ `72px`（移动）
- 圆角统一 `2px`（近乎直角，呼应设定图的硬边分割线）

### 4.4 图形元素

| 元素 | 规格 |
|---|---|
| **断裂圆环** | SVG，2 段弧，缺口 `120°`，线宽 `2px`，hover 时旋转 `90°` |
| **ECG 波形** | SVG path，周期 `240px`，线宽 `1.5px`，用作分隔与签名 |
| **分割线** | `1px` 实线 `--c-gray-200` |
| **分割号** | 文字 `—` 或 `/`，作为标题与内容的连接符 |
| **角标** | 右上角小方块，标注作品编号（如 `NO.004`） |

### 4.5 响应式断点

| 断点 | 宽度 | 处理 |
|---|---|---|
| 桌面 | `≥1280px` | 完整栅格，竖排日文显示 |
| 平板 | `768–1279px` | 8 列，竖排日文转横排 |
| 移动 | `<768px` | 4 列，单栏，LOGO 斜切减小到 −12° |

## 5. 动效规范

> 原则：**动，但克制；简洁中显高级。**
> 动效的作用是「让页面有呼吸和生命」，不是「表演技术」。

### 5.1 三档动效强度

| 档位 | 用在哪| 特征 |
|---|---|---|
| **A档·入场** | 元素首次进入视口 | 一次性，`240–560ms`，只播一次 |
| **B档·交互反馈** | hover / focus / active | 即时响应，`160–240ms` |
| **C档·环境动效** | 常驻循环 | 极缓慢，不抢注意力，页面隐藏时暂停 |

### 5.2 A 档 · 入场动效

**统一的「浮现」语言**：位移 + 透明度，**不用缩放弹跳**（弹跳廉价）。

| 元素 | 动效 | 时长 | 缓动 |
|---|---|---|---|
| 区块标题（大字） | `translateY(24px) → 0` + 透明度 `0 → 1` | `480ms` | `cubic-bezier(.16,1,.3,1)` |
| 正文段落 | 同上，但**比标题延迟 `80ms`** | `480ms` | 同上 |
| 图片卡片 | 透明度 `0 → 1` + `scale(.98) → 1` | `560ms` | 同上 |
| 卡片序列 | 每张**依次延迟 `70ms`**（最多 6 张，之后不再累加） | — | — |
| 分割线（ECG） | `scaleX(0) → 1` 从左展开 | `420ms` | `cubic-bezier(.16,1,.3,1)` |
| 竖排日文 | `opacity 0 → 1`，**不做位移**（竖排文字位移很怪） | `600ms` | ease-out |

**观察方式**：用 `IntersectionObserver`，元素首次 `isIntersecting` 时加 `.is-in` 类并**立即 unobserve**——只播一次。

### 5.3 B 档 · 交互反馈

| 元素 | 动效 | 时长 |
|---|---|---|
| 链接 hover | 下划线从左推进（`scaleX` 0→1） | `240ms` |
| 导航项 hover | 文字下方红色细线展开 | `200ms` |
| 作品卡片 hover | 封面去灰度 + 标题从底部滑出 | `240ms` |
| 断裂圆环 hover | 两段弧**反向张开 90°** | `420ms` |
| 按钮按下 | `scale(.98)` | `120ms` |
| 图片 hover | 边缘出现白色内发光 | `240ms` |

### 5.4 C 档 · 环境动效（页面常驻）

| 元素 | 动效 | 周期 | 说明 |
|---|---|---|---|
| **TOP 首屏圆环** | 两段弧**持续缓慢反向自转** | `40s` / `55s` 一圈 | 首屏视觉核心，最慢 |
| Footer ECG 波形 | 波形**横向缓慢滚动** | `8s` 循环 | 幅度极小，像心电图在跳 |
| TOP 波形线 | 一道红色高光**沿波形掠过** | `6s` 循环 | 每 6 秒一次，很克制 |
| 404 圆环 | 弧段**试图闭合又弹开** | `3s` 循环 | 呼应 SIGNAL LOST |

### 5.5 「高级感」的三个关键

1. **慢而不停滞**：环境动效周期必须在 `6s` 以上，快了廉价
2. **缓动用 `cubic-bezier(.16,1,.3,1)`**（easeOutExpo 系）：起步快、收尾极缓，这是「高级感」的来源
3. **时序错落**：标题先到、正文延迟 `80ms`、图片再延迟 `70ms`——**所有元素同时出现 = 廉价**

### 5.6 无障碍与降级

- `prefers-reduced-motion: reduce` 时：**全部动效关闭**，内容直接可见（不位移）
- 环境动效在 `document.hidden` 时用 `animation-play-state: paused` 暂停
- 视口外的入场动效不播放（`IntersectionObserver` 天然满足）
- 不使用 `backdrop-filter`（移动端性能差）
